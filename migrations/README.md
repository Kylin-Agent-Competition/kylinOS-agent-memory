# Migrations

## 模块定位

SQLite 数据库 schema 版本化迁移管理。所有结构化记忆表结构的变更必须通过本目录中的迁移脚本执行。

## 输入与输出

- **输入**：当前数据库版本与目标版本
- **输出**：迁移后的数据库 schema

## 责任轨道

- **主要**：D
- **审查**：E
