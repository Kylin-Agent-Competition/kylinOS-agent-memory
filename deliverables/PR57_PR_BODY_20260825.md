- **审计结论**：`git log --all -S` 全历史检索确认，首个 Phase 0 证据提交（`b7f7a96`，及 rebase 后 `7f5dba9`）在 `evidence/phase0/phase0_vm_evidence.md/.jsonl` 中**确实曾写入明文 servicekey**（`/etc/.kyinfo` `[servicekey]` 节的值），后续 `740bb62` 引入 `redact()` 后当前 HEAD 已脱敏为 `REDACTED`。

- **影响评估**：LOW——VM 本地 OS 激活信息，非共享凭证，不授予外部系统访问权限。
- **轮换**：不适用（OS 激活 key 非可轮换型凭证；该 VM 为一次性任务虚拟机，随任务重配）。
- **历史处置**：不执行 `filter-branch` 改写历史（治理口径「不轻易 filter-branch」）；建议**本 PR 以 squash-merge 合并**，使含明文的中途提交不进入 main 最终历史。当前 HEAD 已核验无明文（L2-D1 重跑 `key=REDACTED`）。
