## 6. 版本快照与原包备份策略

### 6.1 版本快照（metadata snapshot）

使用 `tools/snapshot_package_versions.sh` 采集当前系统所有 AI Runtime 软件包的精确版本、架构、SHA-256，生成不可变 manifest 文件，作为回退基线参照。

输出文件:
- `packaging/original-packages/package-manifest-<timestamp>.txt` — 带时间戳的精确版本清单
- `packaging/original-packages/package-manifest-latest.txt` — 指向最新快照的链接

Manifest 包含以下字段:
- Package / Version / Architecture / SHA-256 / Status (CACHED/NOT_CACHED) / CachePath

### 6.2 原包备份（actual .deb backup）

在版本快照基础上，需手工备份实际 .deb 文件:

```bash
mkdir -p packaging/original-packages/deb-backup-<timestamp>
for pkg in kylin-ai-runtime libkysdk-ai-common ...; do
    find /var/cache/apt/archives -name "${pkg}_*.deb" -exec cp {} packaging/original-packages/deb-backup-<timestamp>/ \;
done
```

注意: `snapshot_package_versions.sh` 只采集版本元数据，不备份实际 .deb 文件。

### 6.3 备份触发时机

| 时机 | 操作 |
| --- | --- |
| D1 首次 | 通过 SSH 在虚拟机执行版本快照采集脚本 |
| 每次 apt install AI 包 | 重新采集版本快照，同步更新备份 .deb |
| 切换版本前 | 先采集当前版本的快照
