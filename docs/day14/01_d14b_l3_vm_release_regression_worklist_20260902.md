## 固定验收口径

- 干净快照：D14D L3 发布包可安装、可调用真实 SDK，无个人开发目录残留依赖；所有结论绑定同一 Commit 与同一 VM 快照。
- 一致性：删除、重建与服务/OS 重启前后，同一查询（同用户、同版本口径）返回结果集合一致；guardrail/cross_user/sensitive 进入最终 Top-K 均为 Critical，目标为 0。
- 残留：删除后 Vector/FTS5 查询与 SQLite 真源均不再返回该对象；重建后无重复/幽灵命中。
- 性能：按通道记录 P50/P95/mean/max，随 EvalConfig/环境绑定登记，与 D13B 账本口径及既有基线对照。
- 任何正式发布回归达标结论只基于干净快照 VM 实测 + 冻结环境；否则一律标 `UNVERIFIED`。
