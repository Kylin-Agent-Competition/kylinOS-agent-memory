## 一、PR-1：契约先行（纯文档，不写代码）

### 1.1 ADR-010：新增 `turn.finalized` IPC 方法（FRZ-IPC-007 扩展，B-1 方案 A1）

- **路由**：`turn.finalized`（写方法，加入冻结路由表；`memory.store` 保持 UNSUPPORTED 不动）
- **payload**：对齐事件契约 v1 `TurnFinalizedEvent`（`docs/day3/11_os_agent_event_contract_v1.md` §7）：
  - metadata：`schema_version`(必填，接受 `1.x`，≠ `protocol_version`)/`event_id`(必填)/`user_id`(必填)/`session_id`(必填)/`turn_id`(必填)/`idempotency_key`(必填)/`trace_id`(可选)/`occurred_at`(必填)/`collected_at`(必填)/`source_reference`(必填)
  - 事件字段：`is_final=true`(必填)/`finalized_at`(必填)/`final_message_id`/`finalization_reason`/`stop_reason`/`retry_of_turn_id`/`tool_call_ids`
- **错误语义**：非法 payload/缺必填 → `INVALID_REQUEST`；内部异常 → `INTERNAL_ERROR`（safe_error_code，不泄漏 traceback）；未注册方法 → `UNSUPPORTED_METHOD`
- **幂等**：FRZ-IPC-005 三元组 `(user_id, session_id, idempotency_key)`，命中返回缓存
- **响应**：`{db_turn_id, host_turn_id, conversation_id}`（冻结 envelope：status/data/server_ts）

### 1.2 ADR-011：turns 新增 nullable `trace_id` + `host_turn_id`，memory_entries 新增 nullable `trace_id` 列（FRZ-DB-001 扩展，B-2 方案 B1）

- **DDL**：`ALTER TABLE turns ADD COLUMN trace_id VARCHAR NULL`；`ALTER TABLE turns ADD COLUMN host_turn_id VARCHAR NULL`；`ALTER TABLE memory_entries ADD COLUMN trace_id VARCHAR NULL`
- **部分唯一索引**：`CREATE UNIQUE INDEX idx_turns_host_turn_id ON turns (session_id, host_turn_id) WHERE host_turn_id IS NOT NULL`（ADR-010 Upsert 匹配键）
- **迁移**：`migrations/versions/20260826_add_trace_id.py`（upgrade ADD COLUMN / downgrade 表重建，ADR-007 命名 + 禁止删除列，独立 revision，不与 001 冲突）
- **outbox**：不改表；`trace_id` 写入 `payload` JSON（checklist 5.4）
- **向后兼容**：nullable 新增列，既有行不受影响；FTS5 触发器不涉及 trace_id/host_turn_id
