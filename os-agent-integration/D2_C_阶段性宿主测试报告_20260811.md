## 共同阻塞原因

AI 助手的静默服务进程与 Runtime 可运行、可被观察脚本附着，但前台交互窗口无法唤出：以非静默模式启动的进程立即退出。因此无法提交带标记的真实用户消息，也无法诚实触发 PostTurn 回调、PreChat 模型请求或 Tool 的成功/失败/取消场景。

## 明确不能据此得出的结论

- 不能把 `strace` 关键词命中或未命中视为实际模型请求的协议级证明。
- 不能把 Tool 脚本的 N/A、0 计数视为 Tool 行为通过或架构合规。
- 不能把单次 DB 快照视为 PostTurn 的前后变化、15 秒稳定性或 UI/RECORD 一致性。
- 不能运行采集器将本轮原始日志、截图或汇总打包为正式 L2/Gate 证据。
